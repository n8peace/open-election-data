# Security

## Reporting a problem

Please don't open a public issue for a security problem. Use **[Report a vulnerability](https://github.com/n8peace/agent-swarm-election-data/security/advisories/new)** on this repository's Security tab, or message [@n8peace](https://x.com/n8peace) on X. You'll get a reply within 3 days.

Especially useful to hear about:

- A way to change published data without a reviewed pull request (for example, tricking the claim-report recheck into publishing a false claim).
- A way to run up the AI bill from outside, such as through pull requests or issues.
- Instructions hidden in a web page that change how a research agent behaves.
- Leaked keys or personal data.

## What's in place

Paid AI runs only from maintainers' machines, from the nightly check, and from rechecks a maintainer or the Plain Ballot report form labels. The bias review on pull requests never runs a contributor's code. This project stores no accounts and no personal data.
